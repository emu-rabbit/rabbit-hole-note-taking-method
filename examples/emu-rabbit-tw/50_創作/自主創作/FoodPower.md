# FoodPower

FoodPower 是絵夢為 Minecraft 製作的食物力量模組。她想讓食物像 TinkerConstruct 一樣能自由組合，並讓玩家從料理取得力量，因此試著做自己的模組。[^1]

## 從只懂一點 Java 開始
當時她只稍懂 Java，沒有模組開發經驗。沒有 AI 協助，教學又少且難懂，Minecraft 版本還在頻繁更新，讓開發環境更難掌握。[^1]

她尤其記得圖像合成的難關：想把多張 PNG 拼成 Minecraft 物品的外觀，卻看不懂原碼，也找不到能參考的教學。她花了很久才解開，記得自己曾在 Facebook 寫下這件事。[^2]

另有一篇 2020 年的開發貼文記下，她花了一天半試各種參數，直到[[30_故事/故事篇章/函式終於回傳 true|函式終於回傳 true]]。[^3]
