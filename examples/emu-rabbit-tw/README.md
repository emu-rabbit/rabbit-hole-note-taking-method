# 絵夢羽さ沂的兔子洞
## Emu-rabbit's Rabbit Hole

這是絵夢羽さ沂依兔子洞筆記法整理的公開精選範例。內容選取學習、工作、創作、穿著與相處的幾段經歷，讓人物、人生階段、故事、作品與來源彼此連結。人物代稱與來源中的節錄標示保留在各篇裡。

## 開始閱讀

先從 [[00_入口/絵夢羽さ沂|人物概覽]] 認識她，再沿 [[00_入口/閱讀地圖|閱讀地圖]] 選一條路。想看事情的先後，從 [[10_人生脈絡/人生年表|人生年表]] 進入五篇階段文章；想找某個人或作品，使用 [[00_入口/索引|索引]]。

正文註腳連回 [[80_來源/來源目錄|來源]]，可以重讀她當時留下的文字。[[00_入口/兔子洞筆記法|兔子洞筆記法]] 是獨立的方法說明，給 agent 的入口則是 [[AGENTS|閱讀指南]]。

## 用 Obsidian 開啟

1. 解壓縮整個 ZIP，保留資料夾結構。
2. 在 Obsidian 選擇「開啟資料夾為儲存庫」（Open folder as vault），選取含 README.md、00_入口、10_人生脈絡等資料夾的那一層。
3. 開啟 README.md，切換到閱讀模式，即可點選文章連結與註腳。

不需要安裝社群外掛。一般文字編輯器也能閱讀這些 Markdown；雙中括號連結與區塊定位以 Obsidian 為閱讀方式，直接在 GitHub 檔案頁瀏覽時，不會全部轉成可點選的內部連結。

## 範圍

這份範例選錄五個人生階段、幾條生活主題、重要他人、故事、作品與喜好，並保留對應來源。它展示的是一個兔子洞如何組織與串聯內容，不是完整生平。
