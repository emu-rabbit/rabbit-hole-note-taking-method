# 函式終於回傳 true

2020 年，絵夢記下一次開發裡遇到的難題：有個函式看起來能幫上忙，她卻不知道它怎麼運作。它有註解，但她看不懂。她花了整整一天半，試著傳入各種參數，得到的始終是 false。直到它終於回傳 true，她把這件事寫成貼文。[^1]

多年後回憶 [[50_創作/自主創作/FoodPower|FoodPower]] 的開發過程，她仍記得圖像合成的難關。她想把多張 PNG 拼成 Minecraft 物品的外觀，卻看不懂原碼，也找不到教學，花了很久才解開。她印象中曾為這件事發過一篇 Facebook 貼文。[^2]
