# 讓夢夢留在 nAnB 裡

絵夢做了一個聊天室風格的猜數字遊戲 [[50_創作/自主創作/nAnB|nAnB]]，把家裡的[[40_重要關係/寵物/夢夢|黃金鼠夢夢]]放進作品。她在專案 README 裡介紹牠：「夢夢是我家的黃金鼠，她叫夢夢但這是廢話」。[^1]

遊戲裡那張照片是偶然拍下的：夢夢坐在籠子角落，背對鏡頭望著牆。絵夢覺得她像一個有點滄桑的大叔，很有趣，也很喜歡這張照片。[^3]

後來夢夢離世。絵夢在作品集寫道：「夢夢已經去當小天使了，但他就這樣地永遠留在了我的作品中。」[^2]

想認識照片以外的夢夢，可以接著讀[[40_重要關係/寵物/夢夢#在房間裡探索|她在房間裡探索的日常]]。
