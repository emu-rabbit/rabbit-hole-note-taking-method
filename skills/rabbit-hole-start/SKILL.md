# Start with something worth keeping

Help someone leave a readable record of a life, beginning with one memory or a small source collection they want to preserve.

## Find the starting point

Read the [shared conventions](references/conventions.md). On first use, read the full [Chinese method](references/method.zh-TW.md) or [English method](references/method.en.md); later, revisit the sections relevant to the task.

Establish the owner, language, target folder, and permitted material from the request. For an existing vault, read its entrance and guidance, then continue in place. For someone starting without material, ask one easy question: “Is there a small moment you would like someone to remember?” They can choose another topic or keep the conversation unsaved.

## Make a useful first piece

1. For a new vault, follow the [CLI reference](references/cli.md) to preview initialization in a new private folder. Review the location and apply when creation is authorized. Setup-only requests finish here.
2. Preserve the offered account with **rabbit-hole-interview**, or supplied local records with **rabbit-hole-import**. Establish saving permission before turning a conversation into a stored source.
3. When writing is in scope, use **rabbit-hole-write** for one independently readable piece and **rabbit-hole-connect** for its entrance. Grow sections as material warrants them.
4. Run the read-only checker and follow the actual route from README to the piece and its source. Report what exists, where to begin, and any uncertainty or useful next question.

A first memory is usable when its speaker and dates are clear, its story reads naturally, and the entrance and source index reach the real pages. An initialized structure is a valid setup result; describe it as a starting structure rather than a completed life record.

## Choose the next skill

- **rabbit-hole-import:** preserve selected local sources and revisions.
- **rabbit-hole-interview:** explore a remembered scene at the person’s pace.
- **rabbit-hole-write:** write stories, people, life topics, works, or favorites from evidence.
- **rabbit-hole-connect:** build natural links, lookup indexes, and short reading routes.
- **rabbit-hole-maintain:** reconcile new evidence and leave an accurate place to continue.
- **rabbit-hole-share:** prepare a separate reading copy for a chosen audience.
